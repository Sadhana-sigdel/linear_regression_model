# House Price Prediction

A beginner machine learning project using **Python, Pandas, and Scikit-learn** to predict house prices with **Linear Regression**.

## Features

* Area
* Bedrooms
* Bathrooms
* Age
* Parking spaces
* Location score

## Workflow

```text
Load Data → Split Data → Train Model → Predict → Evaluate
```

## Evaluation

The model is evaluated using:

* MSE
* RMSE
* R² Score

The dataset is **synthetic and created for learning purposes**.

## Run

```bash
source .venv/bin/activate
pip install -r requirements.txt
python3 train.py
```
